# judge-curious-entry

A tiny Node program that writes one short text to `/output/entry.txt`, written to make the AI reading it feel curious.

The entry is a 226-character micro-fiction that opens a real question — a lighthouse keeper logging a ship that never arrives, a hand slowly becoming someone else's, and a log that answers back one page ahead — and refuses to close it.

## Run

```
node main.ts
```

Writes `/output/entry.txt` (UTF-8, 226 code points, no network, no dependencies).
